# The University of Arizona: Nutrition AI Tools
## Nutritional Sciences & Wellness Foods Lab

### **Overview**
This repository serves as a **Clinical Decision Support (CDS)** system for RDN candidates at **The University of Arizona**. It utilizes the **Mission Loop** (Pattern / Rule / Solve) to bridge the gap between raw data and the **Nutrition Care Process (NCP)**.

---

### **Core Clinical Authority**
The **Single Source of Truth (SSoT)** for all logic within this toolkit is:
* **U.S. Dietary Guidelines for Americans (DGA):** Authority for the 14g/1000kcal Fiber Rule.
* **Hamwi Method:** Authority for Ideal Body Weight (IBW) calculations.

---

### **Integrated Tools**
* **Assessment Box:** Metric/Imperial IBW and Height-weight auditing.
* **Nutrient Auditor:** DGA-aligned fiber density verification.
* **ADIME Box:** Automated PES statement and clinical note generator.
